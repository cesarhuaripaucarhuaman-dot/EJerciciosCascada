## Menú principal
Abre `index.html` (en la raíz del ZIP, junto a `menu.css`) para ver un menú con enlaces a todos los ejercicios y al cuestionario. Descomprime el ZIP completo antes de abrirlo para que los enlaces funcionen.

## Cómo ejecutar
No se necesita instalar nada: abrir `index.html` de cada carpeta en Chrome, Edge o Firefox (o con la extensión Live Server de VS Code).

## Si no ves animaciones
Solo el Propuesto 4 incluye `prefers-reduced-motion` (lo pide el enunciado). Si tu Windows tiene desactivados los efectos de animación (Configuración → Accesibilidad → Efectos visuales → "Efectos de animación"), ese ejercicio se verá estático a propósito.

## Suposiciones
- Los tres ejercicios resueltos reproducen el código de la guía (con comentarios añadidos); la guía indica que se escriban a mano, así que conviene teclearlos y probar las variaciones de cada paso "Verificar".
- Los propuestos son soluciones propias: colores, textos y medidas son libres según el enunciado.
- En el PDF solo se encontró texto, tablas y bloques de código; no se identificaron imágenes ni capturas con ejercicios adicionales.
- Cada ejercicio usa `index.html` + `styles.css` en su propia carpeta, como indica la guía.
